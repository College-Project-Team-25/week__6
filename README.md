# week__6
# Week 6 — Kelmarsh Wind Forecasting

This repository contains the Week 6 work for **College Project Team 25**, focusing on forecasting wind-related data using the Kelmarsh wind dataset.

## Project Overview

The project explores wind data from the Kelmarsh wind farm and builds a forecasting workflow using Python and Jupyter Notebook. The main notebook, `kelmarsh_wind_forecasting.ipynb`, contains the data exploration, preprocessing, modelling, and evaluation steps.

## Repository Contents

| File | Description |
|---|---|
| `kelmarsh_wind_forecasting.ipynb` | Main Jupyter Notebook containing the wind forecasting analysis and model workflow |
| `Combined_Project_Plans.txt` | Combined project planning document for the team |
| `.gitignore` | Files and folders excluded from version control |
| `README.md` | Project documentation |

## Requirements

To run the notebook, install Python and the required libraries:

```bash
pip install pandas numpy matplotlib seaborn scikit-learn jupyter
```

You can also create and activate a virtual environment first:

```bash
python -m venv venv
source venv/bin/activate  # macOS/Linux
venv\Scripts\activate     # Windows
```

## How to Run

1. Clone the repository:

```bash
git clone [https://github.com/College-Project-Team-25/week__6.git](https://github.com/College-Project-Team-25/week__6.git)
cd week__6
```

2. Install the required packages:

```bash
pip install -r requirements.txt
```

> If `requirements.txt` is not included, install the libraries listed in the Requirements section.

3. Start Jupyter Notebook:

```bash
jupyter notebook
```

4. Open `kelmarsh_wind_forecasting.ipynb` and run the cells from top to bottom.

## Workflow

The notebook follows these main stages:

1. Load and inspect the Kelmarsh wind dataset  
2. Clean and preprocess the data  
3. Perform exploratory data analysis  
4. Create features for forecasting  
5. Train and evaluate forecasting models  
6. Visualise and interpret the results
